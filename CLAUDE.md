# PaperHub

Personal Obsidian paper library: one paper = one folder + one metadata note. Routine `paper-summarizer` / `paper-finder` runs can ignore everything below.

**Framework maintenance.** This repo is the source for a public template at `/Users/howieee/Personal/paper-management-system` (see `notes.md`). Make structural changes to scripts, skills, and docs **here in PaperHub first — never edit the template directly.** After such a change, ask whether it should ship, then run the `public-template-sync` skill to mirror it into the template. Because this vault has no in-folder `.git` (history lives in the out-of-iCloud git backup folder), any framework change or template sync must also be backed up by running the `versioning-with-git` skill.

**Utility changelog policy.** For local PaperHub framework maintenance only, see `.claude/skills/update-paperhub-utils/LOCAL_UTILITY_CHANGELOG_POLICY.md`. Routine paper processing and adopted-copy updater runs can ignore it.
